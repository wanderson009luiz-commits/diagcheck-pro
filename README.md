# DiagCheck Pro

Avaliação técnica de carros usados: checklist com pesos por sistema, códigos OBD, estimativa de reparos, FIPE ajustada pela quilometragem, oferta máxima e laudo em PDF.

**Acesse:** https://wanderson009luiz-commits.github.io/diagcheck-pro/

- Login por e-mail e senha (Supabase). Cada usuário vê só as próprias avaliações.
- Consulta FIPE pela tabela oficial (API pública parallelum.com.br).
- No celular: abra o endereço e use "Adicionar à tela inicial" para instalar como aplicativo.
